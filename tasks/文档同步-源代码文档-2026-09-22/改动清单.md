## 二、已修改文件（共 4 个）

### 1. `src/data/search.py`（175 → 229 行；与文档一致度 1.0000）

搜索链路新增**硬超时**，避免单个数据源卡死拖垮整条回退链：

- 新增导入 `from concurrent.futures import ThreadPoolExecutor`
- 新增常量（均可用环境变量覆盖）：
  - `SEARCH_STAGE_TIMEOUT_SECONDS`（默认 `6`）——单阶段（crawler / duckduckgo）网络上限
  - `SEARCH_CHAIN_DEADLINE_SECONDS`（默认 `12`）——整条回退链硬截止
- 新增 `_run_with_timeout(fn, timeout, *args, **kwargs)`：单阶段硬超时，超时即放弃等待（`pool.shutdown(wait=False)`），`timeout <= 0` 时退化为直接调用
- `_chain_search_impl` 新增整链截止时间 `deadline` 与 `_remaining()`
- **3 处网络调用改造**（crawler 主调用、duckduckgo 回退调用、非 crawler 主调用）统一包成 `_run_with_timeout(fn, min(SEARCH_STAGE_TIMEOUT_SECONDS, _remaining()), ...)`；当 `_remaining() <= 0` 时**直接跳过**，不再发起请求
- 顺带对齐：`fallback_config` 的构造从 `try` 块内提到 `try` 块外（与文档一致）

### 2. `src/four_brain/engine.py`（1787 → 2102 行；与文档一致度 1.0000）

四脑报告管线从「简洁结论」升级为「**详细分报告 + 综合报告**」：

**新增 8 个函数**

| 函数 | 作用 |

| `_prompt_compliance_lines(brain_id, payload)` | 把角色提示词 / 总提示词落实进规则引擎分报告 |

| `generate_synthesis_report_stream(result, provider, research=None, fast=False)` | 流式综合报告；产出 `(增量, 是否完成)` 并回填 `result["report"]` / `result["synthesis"]` |
