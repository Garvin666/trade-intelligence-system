## 四、风险与前置条件
1. **工作区非 git 仓库**：任何文件级改动不可原生命令回退（已为本次任务在 `tasks/.../backup/` 留备份机制，但整体切换仍高风险）。
2. **文档摘录不全**：文档 config 仅给 345/1084 行，`CATEGORY_PARAMS`、函数、`MARKETS` 之外的模型参数均略去 → 切换时需补齐食品版 `CATEGORY_PARAMS`，其余按工作区现有值保留。
3. **文档内部自相矛盾**：文档 config 是食品、文档 engine 默认产品是消费品 → 以"食品方向 + 移除非食品"为准，engine 消费示例需替换为食品。
4. **测试与前端耦合**：现有测试/前端基于 66 消费品类；切到食品后需回归验证，否则既有可能红、前端预设可能失效。
5. **数据规模**：重建 132×15×104 = 205,920 行需重新生成合成数据（现有 `scripts/run_pipeline.py`/`backfill_control_real.py` 可按食品口径跑）。
