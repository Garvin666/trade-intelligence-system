# 小助手运行步骤

## 独立运行

1. 进入目录：`cd 小助手`
2. 创建虚拟环境（可选）：`python -m venv .venv`
3. 安装依赖：`.venv\Scripts\python -m pip install -r requirements.txt`
4. 复制环境变量：`Copy-Item .env.example .env`（已提供运行时 `.env` 时可跳过）
5. 在 `.env` 中填写 `DEEPSEEK_API_KEY` 与 `JWT_SECRET`
6. 启动后端：`.venv\Scripts\python main.py`
7. 浏览器访问：`http://127.0.0.1:8001/login.html`
8. 使用 demo 账号登录：`admin / 123456`；登录成功后跳转到“远帆智品系统”主应用

## 集成到主系统

主后端 `src/api/app.py` 会把本目录中的 `main.py` 挂载到 `/agent`：

1. 从仓库根目录运行：`.venv\Scripts\python scripts\run_api.py`
2. 浏览器访问：`http://127.0.0.1:8000/agent/`
3. 主系统中的“小助手”页在 `/app/agent` 内嵌渲染，不再全页跳转
4. 在 `/agent/` 登录后跳转到主应用 `/app/`，可通过导航再次进入小助手

主 Demo 的 `一键启动.bat` / `start_complete_demo.ps1` 会先打开 `/agent/login.html`，登录成功后进入 `/app/`。

## 验证

登录后输入“电子产品在美国的机会如何”，小助手会调用 `get_market_info` 工具，
再以 SSE 流式返回最终回答。

API key 仅存在于 `小助手\.env`，只被小助手读取；
不要复制到根目录 `.env`、前端文件或提交内容中。
