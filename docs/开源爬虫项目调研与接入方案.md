# GitHub 优秀合法爬虫项目调研与接入方案

> 检索日期：2026-08-16。Star 数与更新时间以 GitHub API 为准，会随时间变化。

## 选型结论

| 项目 | License | Star | 选型理由 | 本项目落点 |
|---|---|---|---|---|
| [apify/crawlee-python](https://github.com/apify/crawlee-python) | Apache-2.0 | 9.4k+ | 活跃维护、Python 原生、请求队列/重试/限速/浏览器可选 | `src/data/crawl_engine.py` 的 HTML 抓取层 |
| [scrapy/protego](https://github.com/scrapy/protego) | BSD-3-Clause | 91 | 现代 robots.txt 解析，支持 `Crawl-delay` / `Request-rate` | `src/data/http.py` 的 robots 门禁 |
| [adbar/trafilatura](https://github.com/adbar/trafilatura) | Apache-2.0 | 6.6k+ | 高精度正文/元数据提取，适合政策页与研究页去噪 | `src/data/http.py` 的 `extract_main_text` |
| [openfoodfacts/openfoodfacts.org](https://world.openfoodfacts.org) | ODbL-1.0（数据） | 官方开放数据 | 免 Key 的开放商品数据库，补充食品品类真实信号 | `src/data/open_food_facts.py` |

三个代码库均以 pip 依赖方式调用，不复制源码；许可证已在 `third_party/PROVENANCE.md` 登记。

## 合规边界

- 只使用 MIT / BSD / Apache / CC0 代码或官方公开 API。
- 每次 HTML 抓取前先查 robots.txt，robots.txt 不可达时 fail-closed 跳过。
- 不启用 Crawlee 的代理轮换、Session 隐身或反检测特性；固定 User-Agent，尊重 `Crawl-delay`。
- 官方 JSON API（Wikimedia、Federal Register、GOV.UK、UN Comtrade、Open Food Facts）继续走轻量 `PoliteFetcher`，避免 690 组每日检索被异步框架拖慢。
- Open Food Facts 的 robots.txt 面向网页爬虫声明 `Disallow: /api`，而 `/api/v2/search` 是其官方文档化的程序接口；适配器按官方 API 文档以标识 User-Agent + 限速调用，不做网页抓取。
- DuckDuckGo HTML 保留为既有可选回退，不新增非官方搜索爬虫；mock 仍是最终回退。

## 代码接入点

### 统一 HTML 爬取引擎

`src/data/crawl_engine.py` 提供 `LegalCrawlEngine`：

```python
engine = LegalCrawlEngine(offline=True)   # 离线模式不发起网络请求
result = engine.fetch("https://example.com")
results = engine.fetch_many(["https://a.com", "https://b.com"])
```

返回结构统一为：

```json
{
  "url": "...",
  "status": 200,
  "html": "...",
  "title": "...",
  "text": "...",
  "provider": "crawlee",
  "fallback_used": false,
  "robots": [],
  "error": null
}
```

### 文本提取与 robots 升级

`src/data/http.py` 新增 `extract_main_text(html, url=None)`：优先用 Trafilatura，失败时回退原正则清洗。`PoliteFetcher` 的 robots 解析已切换为 Protego，并新增 `robots_crawl_delay(url)` 与 `robots_request_rate(url)`。

### 现有脚本迁移

- `src/data/collector.py`：Amazon Best Sellers 抓取改走 `LegalCrawlEngine`，解析函数不变。
- `src/data/policy_sources.py`：gov.cn 政策列表与 EC taxation news 页面改走引擎，官方 JSON API 不变。
- `src/four_brain/data_tools.py`：DuckDuckGo HTML 回退与 `_clean_html` 使用引擎与 Trafilatura。

### Open Food Facts

`src/data/open_food_facts.py` 调用官方搜索 API v2，按市场抓取食品品类商品数、Nutri-Score、品牌与扫描次数，失败回退 mock。快照落在 `output/open_food_facts/latest.json`，状态进入 `data_status.json` 与 `/api/data/status`。
