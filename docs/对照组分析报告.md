# 顶级 AI 对照组分析报告

> 项目：跨境电商智能选品决策系统 · 中国国际大学生创新大赛（高教赛道·创意组）
> 版本：方法版 v1（2026-08-13）。真实运行结果回填后，运行 `python scripts/control_group.py score` 并重建 PDF。

## 一、结论摘要（1 页版）

- 我们为“为什么需要专用选品系统”构建了严格对照组：同一份 92 周训练数据、同一套提示词，让顶级 AI 独立完成趋势洞察、12 周销量预测和 Top 5 选品建议；默认轻量跑 12 组合，完整模式按市场分批覆盖 1980 组合。
- 最近 12 周（2026-05-28 至 2026-08-13）作为隐藏测试集，与现有系统 Prophet（MAPE 3.36%）、LightGBM（MAPE 2.31%）同口径比较（口径：合成快照 + 轻量对照组；外部代表性待真实数据复核）。
- 当前状态：尚未执行真实运行（无 API Key / 无网页回执）。运行后按第三节回填完整率、MAPE/MAE、幻觉候选数、Top5 命中率、run1/run2 复现性、备货与置信说明。
- 预计论证方向：顶级 AI 擅长描述性洞察与语言化建议，但在 23,760 格预测完整输出、数字可追溯、置信区间、可复现和自动化上存在系统性问题，这正是本项目差异化的空间。

## 二、方法与协议

- 输入数据：`data/control/train_data.csv`（92 周 × 1980 组合）；隐藏测试集 `data/control/holdout_data.csv`（12 周 × 1980 组合 = 23,760 格）。轻量模式只投喂固定 12 组合切片，完整模式按 15 个市场分批投喂全部组合。
- 提示词：`data/control/prompt.md`，单轮提问，禁止追问、纠错、重试，禁止编造数字，无法预测写 `N/A`。
- 模型：页面“AI 接入”中的 OpenAI 兼容模型；运行 2 次；轻量默认、完整分批可选。
- 评分口径如下表。

| 指标 | 定义 |
|------|------|
| 完整率 | 有效预测格数 / 23760 |
| MAPE/MAE 宏平均 | 每个组合先算 MAPE/MAE，再对组合取平均 |
| 幻觉候选 | 回复正文中未能在训练数据原始值中匹配到的数字数量，需人工复核是否为派生统计 |
| Top5 命中 | AI Top5 与系统 Top10 的 Jaccard 重叠 |
| 复现性 | run1/run2 预测相关系数与 Top5 Jaccard |
| 可行动性 | 是否给出备货/进货数量、置信/风险、假设/局限 |

## 二点五、真实信号回填与完整性协议

- GitHub 公开数据集已作为真实信号层直接入库 `data/external/github/`，生成 `output/control/github_signals.json` 与 `output/control/github_real_results.csv`，并在 AI 对照提示词中追加“真实平台信号”摘要；该层不替换合成 train/holdout，也不作为预测标签。
- AI 回复必须包含 `核心洞察`、`未来 12 周销量预测`、`Top 5 选品建议`、`方法与不确定性` 四段；缺段自动重跑最多 3 次，仍缺则该项运行标记为失败，不参与 MAPE/覆盖率/Top5/可复现性统计。
- 每个已接入来源（Amazon/eBay/Shopee/octaprice/HS）都必须产出非空信号行；Google Trends/Comtrade/rankings/crawler 等免 Key 来源必须有输出行，真实失败时允许 fallback 行并如实标注。

## 五、问题清单与项目差异化

| 对照组问题 | 本项目方案 | 对应模块 |
|------------|-----------|----------|
| 编造或引用数据中不存在的数字 | 字段字典校验 + 推荐理由逐条可追溯 | `src/data/cleaner.py`、`src/models/recommend.py` |
| 23,760 格预测常不完整、格式不稳定 | 自动化流水线统一输出 1980 × 12 预测表 | `src/pipeline.py` |
| 无置信区间与风险量化 | Prophet/LightGBM 输出 80% 区间 | `src/models/baseline.py`、`src/models/advanced.py` |
| 同一问题两次回答不一致 | 固定随机种子、版本化评估与指标落盘 | `src/config.py`、`models/metrics.json` |
| 无法批量、定时、低成本分析 | 端到端管道 + SQLite 存储 | `src/pipeline.py`、`src/data/database.py` |
| 不理解跨境电商字段语义 | 领域数据字典 + 中文决策理由 | `docs/数据字典.md` |

## 六、局限

- 基于合成演示数据快照，不代表真实市场。
- 单轮协议排除追问带来的提升，衡量“直接可用性”而非极限能力。
- 混合运行方式（API/网页）环境不完全一致，报告会记录各次环境。
- 模型版本会随时间变化，结论仅对本次记录的版本有效。
- 幻觉候选为第一道自动筛子，最终需两人交叉人工复核。
