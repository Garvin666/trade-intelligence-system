## 3. 聚合语义（服务端）

- `category`+`market` 双筛选 → 真实序列（该组合 104 周 / 模型数×90 天），行为与现状一致。
- 仅 category / 仅 market / 无筛选 → 跨组合按日期（history）或 (date, model)（forecast）均值聚合。
- `model` 筛选恒生效；`limit` 为最近 N 期（tail 语义），不泄漏到 `summary`/`recommendations`（990 行 Top20 排序稳定性不受影响）。
- 聚合行补空组合字段（`category=""`/`market=""`），满足前端 `HistoryRow`/`ForecastRow` 类型声明。
- 离线模式（`window.__TRADE_INTEL_OFFLINE__` 55MB 本地快照）与四脑引擎（读 `output/dashboard-data.json` 文件）**均未改动**——仅 API 链路瘦身。

## 5. 双轴审查结论

- **Standards 轴**：核心聚合逻辑正确、兼容性验证无破坏；发现 3 中 4 低问题，已全部修复：
  - 中-1 测试硬编码数据规模 → 动态推导；
  - 中-2 `limit` head/tail 语义不一致 → `_limit_tail` docstring 明示 tail 为图表序列专用语义；
  - 中-3 聚合行缺 `category`/`market` → 补空值满足前端类型；
  - 低-4 docstring 硬编码数字 → 软化；低-5 limit 剔除重复 3 处 → `_without_limit`；低-6 `df["model"]` 加列保护；低-7 分发包未同步 → 已同步。
- **Spec 轴**：判定"可验收"，3 个偏差（limit 文档 head→tail、交付报告落盘、辅助函数命名）已闭环。
