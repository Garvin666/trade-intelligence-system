# 项目优势报告

本项目是"跨境电商智能选品决策系统"，目标用户是中小跨境卖家。它回答四个问题：卖什么、怎么卖、卖到哪、是否值得卖。系统由数据采集、特征工程、预测模型、推荐引擎和贸易决策模块组成，预测部分使用 Prophet 和 LightGBM，语言研究部分可以接入 OpenAI 兼容的大模型。

## 和通用 AI 相比，差别在哪

通用 AI 直接拿提示词回答问题时，擅长描述和总结，但不太适合做大批量、可复现、带数字的选品决策。下面按具体场景说明本项目的差别。

预测是确定性流水线，不是一次生成。系统对 132 个品类、15 个市场（共 1980 个组合）做未来 90 天预测，输出 356400 行结果和 80% 置信区间。同样的输入得到同样的结果，固定随机种子，指标落盘。通用 AI 两次回答同一问题，预测数字通常不同。

决策链路覆盖贸易环节。选品只是入口。系统还计算关税政策影响、到岸成本、汇率敏感性、合规与市场准入、知识产权风险、物流运价、多语言舆情、CBAM 和融资就绪评分。通用 AI 可以解释这些概念，但不会替用户把分散的数据算成一个可执行的结论。

数字可追溯，减少幻觉。推荐评分是 0.35 乘预测增长，加 0.30 乘搜索趋势，加 0.25 乘竞争度反向，加 0.10 乘评论增长。推荐理由按各维度阈值生成。政策与行业事实优先使用官方来源，无法核实的内容标记为"待核实"。通用 AI 在回答中生成的数字，需要人工判断是真实数据还是编造。

数据有更新链路和状态说明。每次启动或按计划任务运行，系统会把数据刷新到当天，生成联网快照、市场日报和 data_status.json，并在看板与 API 展示数据截止时间和来源状态。采集失败时回退并标注，而不是默默给一个看似正常的数字。

可以批量、定时、离线运行。端到端 pipeline、SQLite 存储、FastAPI 和 MCP Server 都可用。演示版内置合成数据，不填 API Key 也能完整跑通；上传用户 CSV 或 JSON 后，可以只基于用户数据生成，关闭联网。通用 AI 通常需要联网调用，无法在无 Key、无网络的环境里完成同样的批量任务。

有对照组，差距是测出来的。项目用同一份 92 周训练数据和 12 周隐藏测试集，让通用 AI 独立完成趋势洞察、12 周销量预测和 Top 5 选品建议，再统一评分。这比口头说"我们更好"更有说服力。

## 实测对照结果

轻量模式实际跑了 12 个组合、144 个预测格，模型是 deepseek-v4-flash。结果如下：

| 项目 | 通用 AI run1 | 通用 AI run2 | 本项目 |
| --- | --- | --- | --- |
| MAPE（宏平均） | 6.94% | 7.52% | LightGBM 2.30%，Prophet 3.36% |
| 覆盖完整率 | 100% | 100% | 流水线全量输出 |
| 幻觉数字候选 | 85 个，18 个待核验 | 40 个，2 个待核验 | 字段字典校验 |
| 两次运行预测相关 | 0.9874 | | 固定种子可复现 |
| Top 5 重叠 | 0.6667 | | 推荐规则固定 |

> 口径注：上表“本项目”列 MAPE 基于合成快照 + 轻量对照组（12 组合），外部代表性待真实数据复核。

配对检验按品类和市场对 MAE 做比较，两次运行的 p 值都是 0.0004883，说明与 LightGBM 的差距不是随机波动。

需要说明，这是轻量口径的结果。完整 23,760 格模式已经实现，但真实结果还没有全部回填；幻觉候选也需要人工复核，区分派生统计和编造。

## 通用 AI 的用处

对照组也承认通用 AI 的长处：描述性洞察、语言化建议、开放式研究。项目没有放弃这部分能力，而是在主 Demo 顶部统一接入 AI，让大模型负责研究综述和报告生成，量化预测和成本计算仍然走确定性引擎。

## 局限

本项目的演示数据是合成快照，不代表真实市场。真实信号层已经接入 Google Trends、平台榜单、UN Comtrade 等来源，但部分付费接口还需要真实 Key 才能跑通。对照组目前只完成了轻量运行，完整分批结果待回填。
