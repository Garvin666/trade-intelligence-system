## 一、交付内容（按建议报告逐项）

### 答辩前必做 ✅

**B4 四脑崩溃止血（最高优先）** — 三层防护：
1. **性能根治**：`src/four_brain/engine.py::build_charts` 热力图预索引，复杂度 O(66×15×102,960)≈1 亿次迭代 → O(102,960)+O(990)；实测 **0.017s**（消除 Windows 原生访问冲突/超时的高负载窗口）。
2. **崩溃隔离**：新增 `src/four_brain/worker.py`，四脑分析在 spawn 子进程执行；worker 崩溃/超时 → 主进程返回 **503 + 中文降级提示**（"本次分析已降级…可关闭'联网研究/AI'后重试"），整站（REST+MCP+前端）不再一起挂；`threading.Lock` 保护进程池并发安全；业务错误（ValueError→400 / FileNotFoundError→404）与崩溃（503）语义分离。
3. **看门狗自动拉起**：`scripts/run_api.py --watchdog` 父进程监护，子进程崩溃指数退避重启（1/2/4/8/16s，每小时上限 5 次，正常退出不重启）；`start_complete_demo.ps1` 默认 watchdog 启动；**实测 kill 子进程后约 2s 自动恢复**。

**B5 自检对齐**：`/api/dashboard-data?meta=1` 轻量元数据（size/mtime/data_as_of，不拉 55MB）；`src/checks.py` 不再探测全量端点，改 15s 超时轻量探测。**实测 `/api/check` connect 组 dashboard_data 6ms ok**（原 5s 超时 fail），API 直调与页面自检结果一致。

**S9 演示占位**：前后端字段名对齐（后端单一事实源）：
- 卖前体检：`PreflightItem.to_dict` 增 `name`(=item)、`message`(=note)；
- 融资尽调：`OsintCheck.to_dict` 增 `title`、`name`、`message`；
- 汇率敏感性：每档增 `margin_pct`（与"利润率%"同值）。
**实测 `/api/trade/decision` 返回三区块全部有值**，前端 `--` 占位消除。
