## 2. 注意事项（本次踩坑）

1. **并行会话共享 `tmp\pytest-check` basetemp 导致 pytest 挂起**：多会话同时跑 pytest 会互删 basetemp。规避：每次全量回归用独立 `--basetemp=tmp\pytest-<名称>`。
2. **并行会话也在改 `src/`**：编辑前先 `git diff`/`grep` 确认工作区状态，编辑失败（file changed）时重新读取再改。
3. **分发包同步**：`发布与材料\完整Demo运行包\` 含独立 `src/` 快照，改完 `src/` 后必须 `Copy-Item` 同步并用哈希校验（AGENTS.md 约定）。
4. **`_dashboard_data_meta` 目录 bug 已在工作区修复**（`ROOT_OUTPUT_DIR`），本轮统一为顶部 `PROJECT_OUTPUT_DIR` import，避免函数内重复 import。
