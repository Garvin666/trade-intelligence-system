# 数据字典

## 统一数据 Schema

所有数据源经过清洗后统一为以下字段，存储于 `data/processed/clean_data.csv` 与 SQLite。

| 字段 | 类型 | 说明 |
|------|------|------|
| `date` | date | 数据日期（周粒度，每日更新至当天） |
| `category` | str | 品类编码：132 个食品 SKU，分属 12 大类，取值见下方品类编码表 |
| `market` | str | 市场编码：15 个，取值见下方市场编码表 |
| `search_index` | float | Google Trends 搜索热度（0-100） |
| `bestseller_rank` | float | Amazon 畅销排名（数值越小越畅销） |
| `price_median` | float | 品类价格中位数（美元） |
| `review_growth` | float | 评论数量周增长率（%） |
| `export_value` | float | 出口金额（万美元，按品类近似折算） |
| `competition_index` | float | 竞争度指数（0-100，越高竞争越激烈） |
| `sales_volume` | float | 周销量指数（目标变量） |

## 品类编码（132 个食品 SKU × 12 大类）

## 国际贸易数据层（规划）

用于关税与政策风险引擎、财务贸易成本模型等模块，数据来源均为官方 / 公开渠道。

| 字段 | 类型 | 说明 |
|------|------|------|
| `tariff_rate` | float | 目标国关税税率（%），来源 CBP / TARIC |
| `policy_effective_date` | date | 政策生效日期，NLP 解析政策公告得到 |
| `policy_risk_level` | int | 政策突变风险等级（0-5） |
| `exchange_rate` | float | 人民币兑目标币种汇率（日 / 周更新） |
| `payment_fee_rate` | float | 支付通道费率（%） |
| `logistics_cost` | float | 单件物流成本（小包 / 海运 / 海外仓） |
| `compliance_cost` | float | 认证与合规成本（美元） |
| `ip_risk_level` | int | 知识产权侵权风险等级（0-5） |

更新频率：行情类按日 / 周更新；政策公告按日抓取并 NLP 解析；用户授权经营数据按订单 / 账期回流。

## 数据信用与供应链金融字段（离线演示版）

由 `src/trade/credit.py` 输出，用于融资就绪评分与远期信用模型设计。

| 字段 | 类型 | 说明 |
|------|------|------|
| `data_coverage_score` | float | 经营数据覆盖度（0-100） |
| `order_stability` | str | 订单稳定性等级（low / medium / high） |
| `completion_rate` | float | 订单履约率（%） |
| `return_rate` | float | 退款率（%） |
| `policy_risk_score` | float | 政策风险调整后评分（0-100） |
| `financing_ready_score` | float | 融资就绪分（0-100） |
| `financing_level` | str | 建议融资档位：供应链金融 / 信用贷 / 小额试单 / 暂不建议 |
| `recommended_data` | list | 真实授信前需沉淀的订单、回款、妥投与税务数据字段 |

## 多脑冲突裁决字段（离线演示版）

由 `src/trade/conflict.py` 输出，用于展示置信度 × 权重的可解释裁决过程。

| 字段 | 类型 | 说明 |
|------|------|------|
| `conflict_level` | str | 冲突等级：low / medium / high |
| `conflict_score_before` | float | 按权重计算的原始综合得分（0-100） |
| `conflict_score_after` | float | 按置信度 × 权重计算的裁决后得分（0-100） |
| `conflict_decision` | str | 风险优先、增长占优或小批量试单等裁决建议 |
| `conflict_reasons` | list | 主导信号与置信度、权重的解释性说明 |
| `conflict_signals` | list | 市场、舆情、政策、物流、财务、准入、融资等 7 类信号明细 |
