## 三、本轮新发现（前端侧实测）

### N-F1. 首页 HeroPanel 首帧显示 "最新销量指数 0 / 模型精度提升 0%"（时序渲染）

- **实测**：`/api/summary` 实际返回 `latest_avg_sales=57.5, mape_improvement_pct=30.87`（数据正常），但首页首帧（数据未返回时）`HeroPanel.tsx:40,44` 渲染默认值 **0 / 0%**，数据到达后才更新为 57.5 / 31%。答辩开场若评委截屏早于数据返回，会看到两个 0。
- **修复方向**：首帧改骨架屏或占位 `--`；或 `/api/summary` 结果预取进 React Query（首页首屏即触发）。

### N-F2. 系统控制台"环境自检"页签首次切换空白（需等待加载）

- **实测**：点击"环境自检" tab 后面板**首次为空**，约 6 秒后内容才出现（React Query 请求 `/api/check` 期间无 loading 占位）。上轮报告 I9 提过"环境自检页签首次切换空白、第二次正常"，本轮复现为**每次全新进入该页都空白 6 秒**（概览 tab 首开正常，仅自检 tab 无 loading 态）。
- **修复方向**：tab 面板加 `isPending` 骨架屏/加载提示；或进入系统控制台即预取 `/api/check`。

### N-F3. 选品看板：筛选后 Top 20 表格空表无提示

- **实测**：看板选"宠物用品 × 美国"后，"Top 20 推荐组合"表格**有表头、0 行**，无任何空状态说明。原因：`/api/recommendations?category=pet&market=us` 返回 0 条——后端默认过滤 No-Go（`services.py:636-637`），而 pet×us 恰为 No-Go（126% 关税）。功能逻辑正确（不推荐 No-Go），但前端对空结果无解释，评委易误判为加载失败/缺数据。
- **修复方向**：表格空态提示"该组合判定为 No-Go（不推荐进入），详见贸易决策"；或前端加 `include_no_go=true` 开关让评委可查看 No-Go 组合及原因。

### N-F4. 贸易决策页多处 `--` 占位（上轮 S9 前端视角）

- **实测**：贸易决策报告"卖前体检"5 项明细（`--：attention / --：pass / --：pending`）、"融资与尽调"5 项明细（`--：pass / --：pending`）、"汇率敏感性"三档（`--%`）仍为占位符——后端未填演示值，前端直接渲染 `--`。
- **修复方向**：后端补齐或前端标注"离线未取到数据"；演示优先选用数据完整组合。
