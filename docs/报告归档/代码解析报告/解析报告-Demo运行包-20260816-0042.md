## 二、核心摘要

`E:\大创\Demo运行包` 是「跨境电商智能选品决策系统」（面向中国国际大学生创新大赛的演示项目）的一个**自包含对外分发运行包**：单文件离线 HTML Demo（52.6 MB）+ 统一 FastAPI 后端 + 四脑选品工作台 + 贸易决策工作台，数据以 46 品类 × 15 市场 × 104 周合成数据为底，双模型（Prophet + LightGBM）预测 + 四维评分推荐，贸易决策覆盖政策/成本/合规/IP/物流/舆情/CBAM/融资/冲突裁决等 12 个环节，真实数据源（Trends/榜单/海关/政策/货源）全部以"适配器 + 分级回退 mock"接入、只作证据层。**最关键的发现是：本副本存在可阻断启动的版本不同步问题——`src/api/services.py` 顶层 import 的 `src.trade.catalog`、`src.data.crawl_quality`、`src.data.real_ingest` 三个模块在本包中缺失，实测 `import src.api.app` 即报 `ModuleNotFoundError` / `ImportError`（config 缺 `REAL_TRAINING_CSV` 等 11 个常量），一键启动的后端无法在本包内直接启动；且文档宣称的 React `/app`、MCP HTTP `/mcp`、后台任务 `/api/jobs` 在本副本中均未实现（前端仍在调用，会 404）。**

## 五、详细分析

### 5.1 包结构拆解（分三层理解本包）

1. **离线层（零依赖）**：直接双击 `跨境电商智能选品系统_最优Demo.html`（或 `离线打开Demo.bat`）即可完整演示可视化看板、四脑工作台、贸易决策工作台——数据全部内嵌，规则引擎浏览器直连；无 Python 也能跑。
2. **在线层（Python 3.10+）**：`一键启动.bat` 装依赖（首次需联网）→ `run_api.py` 起 FastAPI 后端 → 页面获得联网搜索、AI 分析、贸易决策 API、政策刷新等全部能力；启动时后台执行 `complete_demo_refresh.ps1 → run_daily_update.py` 把数据刷新到当天并重建所有页面。
3. **扩展层（可选 Key/CLI）**：`.env` 配置 OpenAI 兼容 Key、Keepa/eBay/Comtrade Key、1688-cli 后自动升级为真实数据源，无 Key 全部回退 mock 并标注。

### 5.2 功能与技术实现梳理

**（1）数据链路**（详见子报告 `解析报告-代码解析-src数据特征模型-20260816-0039.md`）
合成数据（46×15×104 周 = 71,760 行）→ `cleaner` 白名单过滤/去重/填充 → SQLite → `features.builder` 30 维特征（lag/rolling/ewma/growth/diff/季节编码）→ 训练评估：Prophet 基线（log 变换 + 6 外生回归器，90 天日粒度预测）、LightGBM 进阶（30 特征，递归 13 周自回归）、StatsForecast AutoETS 第三基线（仅评估）；推荐 `recommend.py` 为**四维**加权（增长 0.35/搜索 0.30/竞争 0.25/评论 0.10）；产物落 `models/`。真实数据源：Google Trends（pytrends 分批重试，默认仅前 10 品类真实）、平台榜单（amazon 抓取/Keepa/eBay，无 Key skip）、海关出口（Comtrade 免 Key 预览 → OTS → mock）、政策雷达（gov.cn/Federal Register/EU/GOV.UK 官方源，仅 verified 事件进决策链）、货源尽调（1688-cli 子进程，未装回退 mock）、联网信号（Wikimedia 爬虫，robots.txt 前置检查）。

**（2）贸易决策引擎**（详见子报告 `解析报告-贸易决策模块代码解析-20260816-0039.md`）
`build_trade_decision` 编排 12 环节：基础关税测算 → 政策事件量化（新税率 = 基础 + Σ事件税率；单件关税 = max(售价×新税率, 最低关税)；冲击% ≥15%/8% 定 high/medium；±25% 封顶）→ 合规准入（0.6×成本分+0.4×周期分）→ IP 筛查（15 条演示库）→ 物流运价（15 航线 8 周演示序列）→ 卖前体检（四组 pass/attention）→ 多语舆情（11 语种演示统计）→ CBAM 碳成本 → 融资就绪分（档位 ≥85 供应链金融/≥70 信用贷/≥55 小额试单）→ 供应商/客户尽调 → HS 速查 → 冲突裁决（7 信号，置信度×权重归一化）→ 三物流方案排序。报告统一带证据闸与"演示参数可替换"声明。

**（3）统一后端与 API**（详见子报告 `解析报告-统一后端代码解析-20260816-0039.md`）
约 40 个 REST 端点（health/data status/recommendations/trade decision/hs-code/policy events/four-brain/search/AI 配置/控制对照/EDA 等），产物文件为唯一事实源（15s TTL 缓存 + 显式失效热加载）；`ai_config.py` 全局 AI 配置只存进程内存与浏览器 localStorage，脱敏读取、不落盘；`control_run.py` 顶级 AI 对照：lite 12 组合 144 格 / full 按市场分批 8280 格，四段完整性检查 + 重试 3 次 + 幻觉核验评分。

**（4）四脑工作台**（详见子报告 `解析报告-四脑工作台与贸易决策Demo-20260816-0040.md`）
市场分析师/舆情洞察官/供应链评估师/财务精算师四脑各输出 score/direction/confidence/evidence/Markdown 分报告，加权投票（market 0.40 + sentiment 0.30 + finance 0.30，置信度×分数）裁决，供应链 <45 风险降级；AI 模式四脑并发调用大模型（单脑失败回退规则并记 ai_error）；研究代理可自主调工具（web_search/fetch_page/load_dashboard_data/mock_market_data）；支持上传 CSV/JSON 仅基于用户数据（自动 EDA + A/B + 3σ 异常）。

**（5）贸易决策工作台**：`calculate()` 前端计算模型（成本链：采购+物流+佣金+广告+关税+退货+合规+固定+汇率 → 净利/毛利/盈亏平衡/现金周期；四维评分按策略权重合成 decisionScore），目标市场对比即时算 15 市场取前 4，经营沙盘交互记录决策差；AI 三层降级。

**（6）脚本与构建链**（详见子报告 `解析报告-Demo运行包脚本解析-20260816-0039.md`）
`run_daily_update.py`（777 行）7 步：重训 → 政策快照 → 五路真实数据 → 贸易报告 → crawler 信号 + 690 组联网检索快照 + 市场日报 → 刷新 Demo 内嵌数据与 data_status → 重建看板/主 Demo/在线版并同步分发副本（约 110 项硬编码同步清单）；`rebuild_full_demo.py` 是幂等重建入口（strip → 换四脑 → embed 看板/贸易/打磨/在线版）。

**（7）第三方合规**：`third_party/PROVENANCE.md`（2026-08-13 审计）登记 25 个仓库的 License 与提交 SHA，MIT/BSD/Apache/CC0 可直接复用、无 License 仅参考思路；`data/external/github/SOURCES.md` 记录 5 个入库数据集来源与 SHA-256。

### 5.3 可运行性评估

**启动链路（代码层面）**：`一键启动.bat` → 选 Python（优先 `.venv`，否则系统 python/py -3）→ 缺依赖时 `pip install -r requirements.txt` → `start_complete_demo.ps1` → 探测端口 → `run_api.py` → `uvicorn src.api.app:app` → 健康检查 → 打开 `/dashboard` → 后台 `complete_demo_refresh.ps1` 刷新数据并重启后端。

**实测结论（阻断性问题，最高优先级）**：使用根工程 `.venv` 的 Python 3.12 对本包做静态 import 验证——

- `import src.api.services` → **`ModuleNotFoundError: No module named 'src.data.crawl_quality'`**
- `import src.api.app` → **`ImportError: cannot import name 'REAL_TRAINING_CSV' from 'src.config'`**

根因：本副本 `src/` 是**部分同步的混合版本**——`services.py` 是较新版本（顶层 import `src.trade.catalog`、`src.data.crawl_quality`、`src.data.real_ingest`），但对应模块文件与 `config.py` 新常量（`REAL_TRAINING_CSV`、`REAL_FEATURE_BANK_CSV`、`REAL_PROXY_*` 等 11 项）**未随包分发**（这些文件只存在于根工程 `E:\大创\src\` 与 `发布与材料\完整Demo运行包\src\`）。因此在本包目录内直接启动后端会失败，`一键启动.bat` 的"后端已启动→打开页面"路径不可达；唯一可用的在线能力只剩离线 HTML 与浏览器直连。

**离线层可运行性**：HTML 单文件自包含（数据内嵌），双击即可演示看板/四脑/贸易决策，此路径**可用**。

**其余风险**：后端即使补齐文件后，文档宣称的 React `/app`、MCP HTTP `/mcp`、`/api/jobs` 后台任务在本副本均未实现（前端 `build_html_dashboard.py` 的"运行管理"面板调用 `/api/jobs` 会 404）；AI 对照无真实运行记录（需填 Key 后实际跑）；全部真实数据源默认 mock（data_status 已如实标注）。

## 七、问题、风险与不足

按严重度排序：

1. **【阻断】分发副本版本不同步**：`services.py` 引用 3 个未随包分发的模块 + `config.py` 缺 11 个新常量，后端在本包内无法启动（已实测）。修复需从根工程或 `发布与材料\完整Demo运行包` 补齐对应文件（建议直接重新同步 `src/` 全目录）。
2. **【高】文档与代码不一致**：README/AGENTS.md 宣称的能力（React `/app`、MCP HTTP `/mcp`、`/api/jobs` 单进程整合、Streamlit `app.py`、数据分析报告 PDF）在本副本均不存在；前端仍调用 `/api/jobs` 会 404；`运行Demo完整说明.md` 与根 AGENTS.md 对看板 URL（`/dashboard` vs `/app`）表述不一致。
3. **【中】"六维评分 / Go-No-Go"名不副实**：Python 侧 `recommend.py` 实为四维评分且无 Go/No-Go；"six_dimension_score"与 verdict 实际在前端 `build_html_dashboard.py` JS 中用另一套公式计算（输入项仍为 4 个）；两套实现并存、结果不一致，pipeline 产物可能缺 verdict 列。
4. **【中】模型评估口径不统一**：Prophet 按原始行切最近 12 周、LightGBM 按 dropna 后切 12 行，测试集不对齐；Prophet 周频训练/日频预测语义混乱；推荐 growth 将日粒度预测均值与周粒度历史均值直接相除（量纲错配）。
5. **【中】mock 掩盖风险**：Trends 默认 36/46 品类确定性 mock、平台榜单最终必有 mock 行、货源默认全 mock、`collector.collect_customs_exports()` 为占位空实现；`data_status.json` 已标注但页面易被误读为真实数据。
6. **【中】无鉴权与信息泄露**：`POST /api/ai/config`、`/api/control/run` 等匿名可调（AI Key 写入内存后内网可触发付费调用）；全局 500 处理器返回 `str(exc)`；`/eda/reports/{name}` 路径拼接无 basename 校验；BodySizeMiddleware 只查 Content-Length 且会误伤 >64KB 的 `/api/eda` 上传。
7. **【中】性能与体积**：主 Demo 单文件 55 MB（看板 40 MB 数据内嵌），iframe srcdoc 全量注入，首屏加载与浏览器内存压力大；`dashboard-offline.html` 39 MB 与 `dashboard-data.json` 37 MB 并存（离线/在线双模式）。
8. **【低】硬编码与可移植性**：字体路径 `C:\Windows\Fonts\*.ttf`（3 个 PDF 脚本）、端口列表、分发路径含日期 `提交材料包_整合优化版_20260805`、`embed/rebuild` 依赖脆弱字符串标记、`build_html_dashboard` 每次构建子进程跑 pytest（失败回退写死 269）、三份规则引擎实现（`src/backend/four_brain.py`、主工程 `src/four_brain/`、前端 `four-brain-browser.js`）需手动同步、市场定义不纯（ae=中东）。
9. **【低】对照与评测未闭环**：`output/control/score_summary.md` 显示尚无完整两次 AI 对照运行；system_eval 中 ranking 与 robustness 验收未通过（如实保留）；`data/control/responses/` 目录未随包分发。

## 八、结论

本运行包在**设计上**是完成度很高的演示工程：分层清晰（离线单文件 / 在线后端 / 可选真实数据）、四脑与贸易决策的规则引擎逻辑完整可解释、AI 接入统一收敛、证据闸与 mock 标注意识强、第三方合规审计完备、构建链自动化程度高（每日刷新→重建→同步分发包）。但**当前副本处于不可直接启动的状态**（`src/` 部分同步导致后端 import 失败），且存在若干"名实不符"（六维评分、React /app、MCP HTTP、/api/jobs）与口径不一致问题；同时全部演示数据为合成数据、真实数据源默认 mock、对照组无实际运行结果——这些在答辩中需如实区分"演示口径"与"真实能力"。
