## 1. 统一后端架构

**run_api.py 仅 25 行**：设 sys.path → `uvicorn.run("src.api.app:app", host, port, reload=False)`，host/port 取 `BACKEND_HOST`/`BACKEND_PORT`/`API_PORT`（默认 127.0.0.1:8000）。一切能力都在 `src/api/app.py` 单 FastAPI 应用内：

- **中间件链（Starlette BaseHTTPMiddleware + GZip）**，按注册序：
  1. `GZipMiddleware(minimum_size=1024)`：压缩
  2. `RateLimitMiddleware`：每客户端滑动窗口，默认 180 次/60s（`BACKEND_RATE_LIMIT_*` 可配，≤0 关闭），按 `request.client.host` 计数，内存 dict+Lock，超限返 429
  3. `BodySizeMiddleware`：`Content-Length > 65536`（`BACKEND_MAX_BODY_BYTES`）返 413
  4. `SecurityHeadersMiddleware`：`X-Content-Type-Options: nosniff`、`X-Frame-Options: SAMEORIGIN`、`Referrer-Policy: strict-origin-when-cross-origin`
  5. `CORSMiddleware`：`allow_origins=*`（`BACKEND_ALLOWED_ORIGINS` 可配逗号分隔），`allow_credentials=False`，方法/头全放行
- **页面路由**：`/`→重定向 `/docs`；`/dashboard`（优先 `output/dashboard-online.html`，否则根 Demo HTML）；`/output/dashboard.html`、`/output/dashboard-data.json`（max-age=300）；`/dashboard-demo`（旧版）；`/four-brain` 及两个 JS 资源
- **全局异常处理器**：任何未捕获异常返回 500，**消息原样带出 `str(exc)`**

## 3. services.py 实现细节

- **数据层**：`lru_cache(maxsize=1)` 缓存 3 个 CSV（history/forecast/recommendations）；`_CACHE` 二级 TTL 缓存（默认 15s，`BACKEND_CACHE_TTL_SECONDS`），键为 `接口名|过滤键`；`invalidate_caches()` 清双层缓存供刷新后热加载
- **过滤校验**：`_validate` 白名单 category/market/model/platform；日期按字符串比较；limit 截断
- **推荐服务**：按 `six_dimension_score`（回退 score）降序 + rank 升序；默认剔除 `No-Go`（`include_no_go=1` 可含）；输出追加 `recommendable`、`category_name`、`market_name`
- **搜索服务**：`web_search` → `brain_bridge.search`（见 §5 三级回退链），**任何异常一律回退 mock** 并返回 `fallback_used: True` 与 `error` 文本；`online_test` 供自检
- **政策刷新**：`refresh_policy` 调 `src.data.policy_refresh.refresh_policy_snapshot`（默认仅官方源，`include_search` 时用 brain_bridge.search 生成候选）；`policy_watch_payload` 汇总 verified/candidate 计数与来源
- **数据状态**：`data_status()` 优先读 `output/data_status.json`，缺失时用现有产物算回退值；补充 crawler/trends/platform_rankings/suppliers/real_training/real_proxy 各状态 + `crawl_quality` + `decision_data_ready`
- **成本/风险**：`cost_metrics` 用硬编码 15 市场物流费率表 + 公式估算毛利/退货/广告/合规风险，`source: "prototype_estimate"`（诚实标注原型估算）；`risk_overview` 按分数分 high/medium/low
- **贸易 AI**：`trade_ai_analyze` 合并 payload→ai_config→环境变量取 key/base_url/model，要求输出严格 JSON（中英文两套提示词），失败回退本地规则引擎（`mode:"fallback"`）；`_trade_research` 4 查询 `ThreadPoolExecutor(4)` 并发检索

## 4. AI 配置机制（ai_config.py）

- 全局 `_STATE` 内存 dict + RLock；`set_config` 部分合并：api_key/base_url/model/preset/search_provider/search_api_key/search_api_url/timeout(1-600)/search_max_results(1-20)
- **脱敏**：`get_status` 永不返回 key 本身，只给 `configured/has_key/source(memory|env|none)`；base_url 默认 `https://api.deepseek.com/v1`，model 默认 `deepseek-chat`，search_provider 默认 `crawler`
- 优先级恒为 **内存 > 环境变量 > 默认**；注释明确"key 仅存进程内存，不落盘、不返回客户端"；localStorage 由前端自行维护，后端不参与
- 无 `clear_config` 的 API 端点暴露（函数存在但无路由）

## 5. MCP tools 与 brain_bridge（四脑桥接）

**mcp_bridge.py** 暴露 4 个工具（纯函数，mcp SDK 缺失时优雅降级）：`recommendations(top,min_score)`、`trade_decision(category,market,unit_price_usd,procurement_cost_cny)`、`hs_code(category,market)`、`data_status()`；均返回 JSON 字符串、异常包 `{"ok":false,"error":...}`。`_mcp = MCPServer("cross-border-selection")` 在 `from mcp.server.mcpserver import MCPServer` 成功时注册。调用链：`scripts/run_mcp_server.py → get_server().run()`（**stdio**）；`docs/mcp/README.md` 也仅按 stdio 配置。**Demo运行包 后端未挂载 HTTP/SSE 版 MCP**，与根 AGENTS.md"HTTP 方式并入 /mcp"不符。

**brain_bridge.py**：运行时 `importlib` 把 `跨境电商选品AI_Demo/03_可运行系统/src/backend` 注入 sys.path，加载 `four_brain.py`/`ai_provider.py`/`data_tools.py` 及 `dashboard-data.json`（避免复制引擎代码）；`_resolve_data` 支持 `user_data` 上传优先，否则内置数据。四脑桥接提供：`analyze`（use_ai 时按 provider.configured 走 `analyze_with_research`/`analyze_with_ai`，否则规则引擎并附 ai.errors）；`research_only`（无 Key 联网研究：规则分析 + 4 查询并发 + 来源汇总 + 中文总结）；`search`（**crawler(Wikimedia) → duckduckgo_html → mock 三级回退**，空结果/含"请求失败"标题判定失败）；`ai_status`/`ai_test`/`search_test`。

## 6. control_run.py 顶级 AI 对照

- 单任务后台线程：全局 `_JOB`（idle/running/done/error），`start()` 校验 api_key/model（payload→ai_config→env）、mode∈{lite,full}、runs 1-4、temperature、timeout 10-600；**running 时拒绝并发**；`status()` 返回含 progress 的副本
- **lite**：`CONTROL_LITE_COMBOS` 12 组合（12 品类×12 市场）单次请求，12×12=144 格；**full**：按市场分批（每市场一批 → 690 组合×12 周=8280 格），每批一个请求
- `benchmark.run_global_benchmark`：每批 `_call_openai_compatible`（base_url+`/chat/completions`，重试 2 次退避 4/8s，可重试 429/500/502/503/504，其他状态码立即失败）；批次拼合后用 `section_completeness` 检查四段完整性（核心洞察/预测表/Top5/方法不确定性），不完整整 run 重试至 `CONTROL_RETRY_LIMIT`；落盘 `run{n}.md`+`_b*.md`/meta.json，最后 `score_all(["global"])` 写 `output/control/control_metrics.json` + `score_summary.md`
- **评分体系**：`extract_forecast_table`（CSV 代码块/Markdown 表/纯文本 3 级解析）→ 与 holdout merge 算 coverage/MAPE/MAE；Top5 命中（vs 系统推荐+真实增长 Top5，Jaccard）；幻觉核验（数字在训练数据 ±5% 内即 grounded）；备货/置信/假设关键词；run1 vs run2 复现性（预测相关系数+Jaccard）；对系统 LightGBM 基线做配对显著性
- **注意**：完整训练 CSV 切片被**内嵌进提示词**（lite 一次 12 组合、full 每市场一批），token 消耗大；`CONTROL_TIMEOUT_SECONDS=600`

## 8. 问题、不足与可疑点

1. **文档-代码不一致**：根 AGENTS.md 声称"REST+React /app+MCP /mcp+后台任务 /api/jobs 单进程"，本副本均缺失；前端 `build_html_dashboard.py` 的 `/api/jobs` 运维面板调用必然 404
2. **无鉴权**：`POST /api/ai/config`、`/api/control/run`、`/api/scoring/weights`、`/api/feedback` 均匿名可调；AI Key 一旦经页面写入内存，内网任何访问者可触发付费模型调用（限流仅是弱保护）
3. **异常信息泄露**：全局 500 处理器把 `str(exc)` 直接返回给客户端
4. **`/eda/reports/{name}` 路径拼接无 basename 校验**（`EDA_OUTPUT_DIR / name`），存在目录穿越隐患
5. **BodySizeMiddleware 只查 `Content-Length`**：chunked 可绕过；且它拦截所有 >64KB 的 multipart 上传——`POST /api/eda` 传大 CSV 会被 413 误伤
6. **限流器内存无清理**：按 IP 的命中列表只删过期项、不删失效 key，长运行内存缓慢增长；代理场景下 `client.host` 失真
7. **ai_config 进程内存态**：重启即失；多 worker 下各进程状态不一致（当前 uvicorn 单进程无碍）
8. **control_run 无取消/停止机制**；只能单任务；full 模式 15 批 × 重试可能超长
9. **benchmark 遗留**：`_call_openai`/`_call_anthropic`/`_call_gemini`/`_call_deepseek` 四套硬编码调用存在，但 `MODEL_REGISTRY` 只注册 deepseek（旧代码未清理）；提示词内嵌整段 CSV，token 开销大
10. **cost_metrics 硬编码公式**：风险评分/物流费率表为原型估算（已标 `prototype_estimate`，但数字可能误导决策）
11. **platform_rankings 非真实平台数据**：用 history 最新周模拟榜单排序
12. **`analysis_charts` 双模型对比**：`advanced["mape"].values` 按位置对齐 baseline，假设行序一致，存在错位风险
13. **publish.py**：把 JSON 文本注入 Demo HTML 常量（仅转义 `</`→`<\/`），找不到 `refreshStatus` 锚点即抛异常；依赖 Demo 包路径 `发布与材料\完整Demo运行包`
14. **mock 回退不透明**：`web_search` 任何异常都返回 mock 结果 + error 字段，前端需自行判断真实性（界面有标注）

## 结论

Demo运行包 的统一后端是"单 FastAPI 进程承载 REST 聚合 + 页面静态服务 + 内存 AI 配置 + 四脑桥接 + 后台对照线程"的轻量架构，数据以产物文件为唯一事实源（TTL 缓存 + 显式失效），搜索走 crawler→duckduckgo→mock 回退链并全程标注。真实风险集中在"无鉴权 + 异常/路径信息泄露 + 文档宣称能力（/mcp、/api/jobs、/app）与代码不符"三点；trade 决策链与对照组评分逻辑实现完整、口径严谨，是系统价值主体。
