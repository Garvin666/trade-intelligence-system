# 路演大纲（10 分钟）

## 一、项目定位

| 维度 | 内容 |
|------|------|
| 项目名称 | 基于多源数据融合的跨境电商智能选品决策系统 |
| 升级定位 | 跨境贸易决策智能（Trade Intelligence） |
| 一句话定位 | 以选品为入口，用 AI 实时聚合国际贸易政策、成本与风险，帮中小卖家回答"卖什么、怎么卖、卖到哪、是否值得卖" |
| 核心主线 | 政策变化快于人工跟踪 → 到岸成本与合规风险成为利润关键 → AI 提供实时测算与决策建议 |

## 二、时间轴总览

| 时长 | 环节 | 核心目标 | 演示 / 素材 |
|------|------|----------|------------|
| 1 分钟 | 开场 | 一句话讲清"我们是谁、解决什么问题" | 看板首页 / 一句话金句 |

## 三、分环节细纲

### 环节 1：开场（1 分钟）

- 一句话：当关税、汇率、合规规则每天都在变化，我们用 AI 跟踪政策、测算到岸成本，替中小跨境卖家做出"卖什么、怎么卖、卖到哪"的决策建议。
- 关键动作：屏幕打开看板首页，展示"跨境贸易决策智能（Trade Intelligence）"标题。
- 过渡句：为什么现在必须做这件事？因为国际贸易政策正在快速改变卖家的成本结构。

### 环节 2：痛点与机会（2 分钟）

政策痛点：

- 美国 2025 年取消 800 美元以下小额包裹免税，欧盟 2026 年 7 月起对低价值包裹征税
- 政策变化速度超过人工跟踪能力，中小卖家普遍缺数据团队
- 选品、关税、汇率、合规、物流成本分散在多个平台，试错成本高

市场机会：

- 2025 年中国跨境电商进出口 2.75 万亿元，较 2020 年增长 69.7%，企业超 12 万家
- AI 实时监控目标国法规变化成为跨境电商 SaaS 核心趋势
- Temu 已用 AI 实时监测关税变化并自动调整，需求已被验证

一句话总结：政策变化的速度已经超过人工能跟踪的速度，"AI 监控 + 实时成本测算"从可选项变成刚需。

### 环节 3：产品 Demo（4 分钟）

演示顺序：

1. 选品看板：多源热度趋势、未来 90 天预测、Top 10 推荐与理由、市场对比
2. 政策风险引擎：模拟关税上调后到岸成本与利润变化，触发预警
3. 应对建议：转正式清关 / 调价 / 切换市场 / 海外仓本地发货
4. 贸易成本测算：关税 + 汇率 + 支付费率 + 认证合规 + 物流三方案（小包 / 海运 / 海外仓）
5. 市场准入筛查：合规清单、认证成本、知识产权侵权风险等级
6. 数据信用与供应链金融（远期叙事）：融资就绪分、建议融资档位与需沉淀的授权数据字段

一句话总结：选品只是入口，政策、成本与风险才是这套系统的护城河。

### 环节 4.5：对照组：顶级 AI 的边界（1 分钟）

- 用同一份 92 周数据 + 统一提示词，测了 ChatGPT / Claude / Gemini / DeepSeek 的端到端选品分析
- 结论（待对照组报告回填）：通用 AI 擅长描述洞察，但在预测完整率、数字可追溯、置信区间与复现性上存在缺口
- 完整证据：`docs/对照组分析报告.md` 与 `output/pdf/顶级AI对照组分析报告.pdf`

### 环节 4：技术亮点（2 分钟）

- 两层架构：国际贸易数据层（关税税率库、汇率行情、政策公告 NLP、物流运价、专利商标、法规合规）→ 分析内核（大脑 1 市场、大脑 2 舆情、大脑 3 供应链与政策、大脑 4 财务）→ 综合决策报告
- 多源数据融合 + 双模型预测：Prophet 基线 + LightGBM 进阶，LightGBM MAPE 2.29%（口径：合成快照 + 轻量对照组；外部代表性待真实数据复核）
- 冲突裁决：置信度 × 权重，用"市场热销但供应链断货"等案例说明裁决逻辑
- 数据合规：优先官方 API 与公开政策库（Amazon SP-API、Shopee Open Platform、CBP、TARIC、USPTO）
- FastAPI 演示服务：将贸易决策、演示报告、推荐与政策事件暴露为可集成的 JSON API

### 环节 5：商业模式与团队（1 分钟）

- 商业模式：SaaS 订阅 + 企业定制 + 行业数据报告；供应链金融数据服务列入远期 Roadmap，融资就绪评分已有离线演示版
- 团队：数据、算法、产品、商业四类角色，并补充跨境电商 / 国际贸易背景成员或顾问

### 环节 6：结尾（30 秒）

政策变化的速度已经超过人工能跟踪的速度；我们让数据替卖家做更难、更及时的决定。
