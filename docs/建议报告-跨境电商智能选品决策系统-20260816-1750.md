## 二、本轮新增问题（最重要，按严重度排序）

### M1 🔴 联网检索 100% mock 却宣称"完成联网检索、20 条有效链接"——fallback 标记丢失（数据真实性）

**复现（实测）**：页面四脑工作台"开始四脑分析"→ 报告显示：
> "完成 4 组联网检索，共 20 条来源（含有效链接 20 条）；主题覆盖市场趋势、政策合规与用户反馈。"

但"证据来源"6 条全部是 `Mock result for 智能宠物喂食器 美国 宠物用品 market trend competition`（`source:"mock"`、`snippet:"Offline mode: no network request was made by the legal crawler."`）。API 层复测同 payload：`steps` 显示 `provider=crawler fallback=False`，与 sources 全 mock **自相矛盾**。

**根因（代码定位）**：`src/four_brain/data_tools.py:349-377` `crawler_search()` 调用 `legal_crawler.crawler_search(query, max_results)` **未传 offline** → 真实网络请求失败 → legal_crawler 内部回退 mock 并正确置 `fallback_used=True`（`legal_crawler.py:167-177, 198-208`）；但 data_tools 用 `fallback_used = not results and not pageviews` **重新计算**（369 行）——mock 结果非空 → **误判 `fallback_used=False`**。下游 `search.py:59` 的 `chain_search` 据此判定成功（`failed=False`），不再走 duckduckgo→mock 回退链，fallback 标记彻底丢失；`brain_bridge.py:332-337` 的 summary 因此不追加"已标注为模拟结果"，且 `valid = [s for s in sources if s.get("link")]` 把 mock 自带的 duckduckgo 链接（`legal_crawler.py:129`）全部计入"有效链接 20 条"。

**影响**：① 评委问"联网搜到了什么"→ 展示全 mock；② "证据分 78.5 / 真实证据接入 high"（来自 github_real 代理特征）与"联网 20 条来源"叠加，极易被解读为实时联网证据充分；③ 证据闸的"mock 不进入证据分"标注体系在**四脑实时搜索链路**失效（每日更新链路的 `crawl_quality` 正确统计了 crawler mock，但四脑链路绕过了它）。

**修复方向**：
1. `data_tools.crawler_search` 保留 `legal_crawler` 返回的 `fallback_used/provider`，不再重算；或显式传 offline 并透传标记（一行级修复）；
2. `brain_bridge.py` 的 `valid` 过滤排除 `source=="mock"` 条目；summary 在 mock 占比>0 时强制标注"（N 条为离线模拟，未联网）"；
3. UI 层对 `source=="mock"` 的来源渲染"模拟"角标，并把"完成联网检索"改为按真实计数表述。

### M3 🔴 政策严重度分级倒挂（数据语义错误）

**实测**：看板"政策雷达"与 `output/dashboard-data.json` `trade.policy_events`（23 条）：
- **low**：「美国取消小额包裹免税」（`rate_ad_valorem=1.20`，120% 关税，全系统影响最大的政策事件）、「欧盟低值包裹征税」（20% VAT）；
- **high**：「EU receives €1.4 billion…Russian assets…Ukraine」（俄乌资产，与选品无关）、「Imposition of Import Restrictions…Nepal」（尼泊尔文物，与选品无关）。

**根因**：`src/trade/policy.py:797-831` 种子事件 `POLICY_EVENTS` 定义中，de minimis 与欧盟 VAT 两条**未设置 `impact_level`** → 命中 `PolicyEvent` 默认值 `"low"`（787 行）；而 high 的两条来自官方源爬虫抓取的原始文本，严重度按原文语义标注。**严重度没有业务语义**：对选品决策影响最大的事件显示"低"，无关宏观新闻显示"高"。

**影响**：评委按"高严重度"优先查看政策雷达时，会先看到两条无关事件；de minimis 这种决定性政策反而被标"低"，与贸易决策页"有效关税 126%、+521.1% 到岸成本变化"的业务结论自相矛盾（B1 的过滤/计算逻辑是对的，**展示层严重度错了**）。

**修复方向**：种子事件显式设置 `impact_level="high"`（de minimis、欧盟 VAT），或按 `rate_ad_valorem/min_duty_usd/cost_adjustment_pct` 自动推导严重度（如税率≥20% 或 cost 变化≥50% → high）；crawler 抓取事件按关税/合规语义重分级，宏观新闻降级为"参考"。
