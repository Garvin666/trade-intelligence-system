## 3. 构建与验证流程

### 3.1 环境

### 3.2 单测验证（Windows 本机）

```powershell
# 结果：413 passed / 0 skipped / 0 failed（941s，最终代码）
```

### 3.3 性能验证（build_charts）
- 102,960 行 history：**0.017s**（原实现 O(1 亿次) 迭代窗口，消除崩溃/超时高负载点）。

### 3.4 子进程隔离验证
- `FOUR_BRAIN_ISOLATED=1`（默认）：四脑分析在 spawn 子进程执行，worker 超时→RuntimeError→API 503 降级提示，主进程存活。
- 超时降级后池自动重建，再次分析正常（实测 5.9s 完成）。

### 3.5 看门狗验证（8020 端口实测）
- `python scripts/run_api.py --watchdog` 启动 → `/api/health` ok。
- `Stop-Process` kill 子进程 → **约 2s 内自动重启**（新 pid），健康检查恢复。
- 退出码 0（正常 shutdown）不重启；每小时超 5 次停止。

### 3.6 端到端实测（8010 实例，watchdog 模式）
- `/api/check?groups=connect`：**ok=13 warn=0 fail=0**；`connect.dashboard_data` **ok / 6ms**（原 5s 超时 fail）。
- `/api/dashboard-data?meta=1`：ok=True，53MB，data_as_of=2026-08-16，**不含 history 全量**。
- `/api/four-brain`（mock 搜索）：category=small_appliance，charts=4，隔离执行成功。
- `/api/trade/decision?category=home&market=us`：preflight items 含 `name/message/status`；osint checks 含 `title/status`，readiness=ready；fx_sensitivity 档含 `margin_pct`（与"利润率%"同值）——前端 `--` 占位消除。
