# 跨境电商智能选品决策系统 · 项目大纲

> 中国国际大学生创新大赛 · 高教赛道 · 创意组 · 国际贸易 × AI 数据

**一句话定位**：以选品为入口，用 AI 实时聚合国际贸易政策、成本与风险，帮中小卖家回答"卖什么、怎么卖、卖到哪、是否值得卖"。

## 01 项目定位

本项目定位为跨境贸易决策智能（Trade Intelligence）。选品只是入口，贸易政策、成本与合规风险才是真正的护城河；系统把分散在多个平台的关税、汇率、合规、物流与市场数据收拢到一套决策链路中，替代卖家的人工查表与经验试错。

- 项目名称：基于多源数据融合的跨境电商智能选品决策系统
- 升级定位：跨境贸易决策智能（Trade Intelligence）
- 目标用户：Amazon / 速卖通 / Shopee / Temu 中小卖家，外贸选品团队、供应链企业与独立站运营者
- 核心闭环：多源数据 → 趋势预测 → 选品推荐 → 贸易成本与风险测算 → 决策建议
- 核心价值：政策变化的速度已经超过人工能跟踪的速度，"AI 监控 + 实时成本测算"从可选项变成刚需
- 数据合规原则：优先官方 API 与公开政策库（CBP / TARIC / USPTO / EUIPO / 汇率与运价指数），用户经营数据在授权与脱敏前提下回流
- 参赛赛道：中国国际大学生创新大赛 · 高教赛道 · 创意组

## 02 为什么是现在

### 政策变化快于人工

- 美国 2025 年取消 800 美元以下小额包裹 de minimis 免税
- 欧盟 2026 年 7 月 1 日起对 150 欧元以下低价值包裹征税
- 政策生效后有效税率、单件关税与到岸成本都会变化，卖家需要实时测算而非事后补救

### 市场已被验证

- 2025 年中国跨境电商进出口 2.75 万亿元，较 2020 年增长 69.7%，企业超 12 万家
- 选品是最高频、最影响成败的决策；中小卖家普遍缺少数据团队
- 关税、汇率、合规与物流成本分散在多平台，试错成本高

### 行业趋势已验证

- Temu 已用 AI 实时监测关税变化并自动调整
- "AI 监控目标国法规（关税、数据隐私、质量标准、知识产权）"成为跨境 SaaS 核心趋势
- 现有竞品偏关键词与流量工具，缺少政策、成本与风险的一体化决策建议

## 03 我们怎么做

### 国际贸易数据层

关税税率库 · 汇率行情 · 政策公告 NLP · 物流运价指数 · 专利商标库 · 法规合规库

数据来源与更新频率：

- 政策公告：CBP / TARIC 按日抓取并 NLP 解析，写入政策事件与更新税率库
- 行情类：汇率、运价指数、搜索热度按日 / 周更新
- 平台数据：Amazon SP-API / Ads API、Shopee Open Platform（规划）
- 知识产权：USPTO / EUIPO 官方公开数据（规划）
- 用户回流：授权与脱敏后的订单、履约、退款与回款数据，用于运营诊断与远期信用评分

### 数据管道与特征工程

1. 采集：可扩展采集框架；演示数据生成带趋势、季节性与品类差异的合成数据，保证离线可运行
2. 清洗：统一 Schema、去重、枚举校验、缺失值填充，写入 `clean_data.csv` 与 SQLite
3. 特征：20 个特征列，包含目标变量滞后（lag 1/2/4/8）、滚动统计（4/8 周均值）、增长率与差分、月份 / 周数季节编码
4. 规划特征：外部事件（关税政策生效日期、汇率跳变、Prime Day / 黑五）

### 分析内核：四大脑 + 冲突裁决

```text
大脑 1 市场 → 大脑 2 舆情 → 大脑 3 供应链 / 政策 → 大脑 4 财务（含关税、汇率）
        ↓ 冲突裁决：置信度 × 决策权重
综合决策报告
```

- 每个大脑输出结论时附带置信度（数据完整度 × 模型拟合度）
- 冲突场景按"置信度 × 决策权重"裁决，权重来源为卖家调研的决策因子排序
- 示例："市场热销但供应链断货"时，供应链 / 政策风险权重更高，推荐转向替代品类或调整备货方案
- 冲突裁决已实现：`src/trade/conflict.py` 将市场、舆情、政策、物流、财务、准入、融资 7 类信号按置信度 × 权重输出裁决等级、裁决后得分与风险优先建议，并接入报告、看板与 API

### 双模型预测

| 模型 | 方法 | 表现 |
|------|------|------|
| Prophet 基线 | 多源外生回归变量，对数变换，周 / 年季节性 | MAPE 3.36% |
| LightGBM 进阶 | 30 特征梯度提升，滚动递归预测 | MAPE 2.29% |

> 口径注：本表 MAPE 基于合成快照 + 轻量对照组，外部代表性待真实数据复核。

相对提升约 32%，满足计划验收标准（相对提升 ≥ 10%）；输出未来 90 天日粒度预测与 80% 置信区间。

### 推荐引擎与决策输出

综合评分 = 0.35 × 预测增长 + 0.30 × 搜索趋势 + 0.25 × 竞争度（反向）+ 0.10 × 评论增长

- 决策输出：选品 Top N、到岸成本测算、政策风险预警、市场准入建议
- 推荐理由：根据各维度阈值自动生成中文说明，覆盖高增长、搜索升温、蓝海 / 红海、评论活跃、政策预警
- 展示层：Streamlit 看板 + FastAPI 演示服务，贸易决策、演示报告、推荐与政策事件均可通过 JSON API 集成

## 04 已经做到哪

### 核心成果

- 端到端流水线 + Streamlit 看板 + FastAPI 演示服务
- 双模型预测：Prophet 基线 MAPE 3.36% → LightGBM 进阶 2.29%（相对提升约 32%）（口径：合成快照 + 轻量对照组；外部代表性待真实数据复核）
- 1980 组合（132 品类 × 15 市场）× 90 天 × 2 模型，共 356400 行预测
- 106 / 106 自动化测试通过；指标落盘 + 版本化评估，固定随机种子保证可复现

### 贸易决策模块（演示版已实现）

- 关税与政策风险引擎：政策事件、有效税率、单件关税、到岸成本上升、利润冲击与应对建议（转正式清关、调价、切换市场、海外仓本地发货）
- 财务贸易成本模型：采购、关税、汇率敏感性（±5%）、支付通道、认证合规与物流三方案（小包直邮 / 海运整柜 / 海外仓本地发货）
- 合规与市场准入：IOSS / VAT、CE / FCC / FDA / RoHS / CPSC / GPSR 清单，认证成本、周期与准入可行性评分
- 知识产权风险筛查：内置商标 / 专利 / 外观设计库，按品类 × 市场输出低 / 中 / 高风险，支持候选品名称匹配
- 物流运价与时效预测：SCFI 风格演示运价序列，预测未来 4 周指数、单件物流成本、交付时效与拥堵风险
- 多语言舆情与本地化：英 / 西 / 德 / 日 / 葡情感词库，输出情绪分、正 / 负 / 中性占比、趋势与本地化建议
- 绿色贸易与 CBAM 前瞻：按市场 / 品类输出 CBAM 暴露度、预估碳成本与政策趋势
- 数据信用与供应链金融：输出融资就绪评分与建议融资档位（供应链金融 / 信用贷 / 小额试单 / 暂不建议）
- 多脑冲突裁决：按置信度 × 权重融合 7 类异构信号，输出冲突等级、裁决后得分与风险优先建议

### API 演示服务

- `GET /api/health`：健康检查
- `GET /api/policy/events`：政策事件监控清单
- `GET /api/trade/decision`：按品类 / 市场 / 售价 / 采购成本返回完整贸易决策
- `GET /api/trade/report`：最近一次 1980 组合演示报告
- `GET /api/recommendations`：Top N 选品推荐

## 05 为什么是我们

### 对照顶级 AI

用同一份 92 周训练数据 + 12 周隐藏测试集（1980 组合 × 12 周 = 23,760 格）+ 统一提示词，让 DeepSeek 独立完成趋势洞察、12 周销量预测与 Top 5 选品建议，运行 2 次。评分口径包括完整率、MAPE / MAE、幻觉候选数、Top 5 命中、复现性与可行动性。

- 通用 AI 擅长描述性洞察与语言化建议
- 在预测完整率、数字可追溯、置信区间、可复现与批量自动化上存在系统性缺口
- 本项目用字段字典校验、统一预测表、80% 置信区间、固定随机种子与指标落盘补齐这些缺口

- 数据规模：205,920 条周粒度清洗数据、104 周、132 品类 × 15 市场 1980 组合，预测产物 356,400 行
