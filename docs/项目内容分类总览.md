## 3. 核心源码 `src/`

### 3.1 配置与流水线

- `src/config.py`：品类、市场、路径、模型与推荐权重等全局配置。
- `src/pipeline.py`：数据到推荐的端到端流水线。
- `src/checks.py`：环境自检与系统检查逻辑。

### 3.2 数据层 `src/data/`（26 个模块）

- 基础采集与清洗：`collector.py`、`cleaner.py`、`synthetic.py`、`base.py`、`database.py`。
- 联网与搜索：`crawl_engine.py`、`crawler_signals.py`、`search.py`、`http.py`。
- 真实数据适配器：`real_features.py`、`real_ingest.py`、`hf_datasets.py`、`open_food_facts.py`、`github_datasets.py`、`trends.py`、`platform_rankings.py`、`customs.py`、`supplier_sourcing.py`。
- 每日更新与政策：`daily.py`、`market_daily.py`、`policy_common.py`、`policy_refresh.py`、`policy_sources.py`、`legal_crawler.py`。

### 3.3 特征与模型

- `src/features/builder.py`：滞后、滚动、趋势、季节性等特征工程。
- `src/models/baseline.py`、`advanced.py`、`statsforecast_baseline.py`：三种预测基线。
- `src/models/recommend.py`：Top N 推荐与六维评分。
- `src/models/real_proxy.py`：真实销量代理模型。
- `src/models/metrics.py`：模型评估指标。

### 3.4 贸易决策 `src/trade/`（17 个模块）

覆盖关税政策（`policy.py`、`compliance.py`）、成本（`cost.py`、`logistics.py`）、HS 速查（`hs_code.py`）、合规与 IP（`conflict.py`、`ip.py`）、舆情（`sentiment.py`）、尽调（`preflight.py`、`osint.py`、`supplier_sourcing.py` 相关）、绿色贸易（`green.py`）、信用融资（`credit.py`）、机会评估（`opportunity.py`）、决策与报告（`decision.py`、`report.py`、`catalog.py`）。

### 3.5 分析与展示

- `src/analysis/`：EDA、异常检测、统计检验、证据闸与报告生成。
- `src/app/dashboard.py`：Streamlit 看板。
- `src/api/`：FastAPI 统一后端（`app.py`、`services.py`、`jobs.py`、`ai_config.py`、`mcp_bridge.py`、`control_run.py`、`examples.py`、`middleware.py`、`store.py`、`brain_bridge.py`）。
- `src/four_brain/`：四脑工作台引擎（`engine.py`、`ai_agent.py`、`ai_provider.py`、`data_tools.py`）。
- `src/control/`：顶级 AI 对照评测（`benchmark.py`、`publish.py`）。

## 4. 脚本 `scripts/`

### 4.1 流水线与训练

- `run_pipeline.py`：数据 → 清洗 → 训练 → 预测 → 推荐。
- `train_models.py`、`train_real_enhanced.py`、`run_real_validation.py`。
- `run_statsforecast_baseline.py`、`optimize_models.py`、`compare_model_metrics.py`。

### 4.2 数据更新与联网

- `run_daily_update.py`：每日刷新到当天 + 联网快照 + 重建。
- `run_policy_watch.py`、`run_legal_crawler.py`、`test_policy_sources.py`。
- `build_market_daily.py`、`backfill_control_real.py`、`fetch_github_datasets.py`。
- `build_hf_real.py`、`build_datasets_inventory.py`、`build_datasets_index.py`。

### 4.3 报告与构建

- `run_data_analysis.py`、`build_data_analysis_pdf.py`。
- `run_trade_demo.py`、`build_trade_catalog.py`、`build_control_report_pdf.py`。
- `build_outline_pdf.py`、`build_progress_pdf.py`、`build_system_eval.py`、`build_eng_status.py`。
- `build_html_dashboard.py`、`verify_dashboard.py`、`verify_html_dashboard.py`。

### 4.4 服务与运维

- `run_api.py`：统一后端（REST + React 前端 + MCP + 后台任务）。
- `run_mcp_server.py`：MCP 独立 stdio 入口。
- `run_env_check.py`：环境自检。
- `control_group.py`：顶级 AI 对照运行。
- `install_daily_update_task.ps1`、`install_policy_watch_task.ps1`：Windows 计划任务注册。
- `complete_demo_refresh.ps1`、`run_daily_update.bat`：Demo 刷新辅助。
- `generate_demo_data.py`：演示数据生成。

## 5. 前端 `frontend/`

技术栈：React 19 + TypeScript + Vite + Tailwind 风格 CSS + ECharts + GSAP + Three.js + Radix UI，包管理使用 pnpm。

- `frontend/src/features/`：按业务域组织，包括 `dashboard`、`trade-decision`、`four-brain`、`workbench`、`system`、`demo`。
- `frontend/src/pages/`：Home、Dashboard、Workbench、Trade、Plans、System、About。
- `frontend/src/shared/`：API 客户端、状态、品牌组件、图表、UI 组件、样式与工具函数。
- `frontend/src/widgets/`：AppShell、TopNav、HeroPanel、统一配置栏等应用外壳。
- 构建产物：`frontend/dist/`（在线版）、`frontend/dist-offline/`（离线版），同步到 `output/app/` 与 `output/app-offline.html`。
- 前端测试：`frontend/src/test/`，使用 Vitest。

## 6. 数据资产 `data/`

| 子目录 | 内容 | 规模 |
| --- | --- | --- |
