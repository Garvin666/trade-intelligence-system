# 技术文档

## 1. 系统架构

两层架构：国际贸易数据层 + 分析内核，最终输出综合决策报告。

```text
【国际贸易数据层】
关税税率库｜汇率行情｜政策公告 NLP｜物流运价指数｜专利商标库｜法规合规库
        ↓ 数据分流与标准化
【分析内核】
大脑 1 市场 → 大脑 2 舆情 → 大脑 3 供应链 / 政策 → 大脑 4 财务（含关税、汇率）
        ↓ 冲突裁决（置信度 × 权重）
【综合决策报告】
选品推荐、到岸成本测算、政策风险预警、市场准入建议
  展示层：统一后端 React 前端 /app（Streamlit 兼容入口 src/app/dashboard.py） / 报告
```

## 2. 数据管道

1. 数据源采集：`src/data/collector.py` 提供可扩展采集框架，规划接入官方 API（Amazon SP-API / Ads API、Shopee Open Platform）、公开政策库（CBP、TARIC、USPTO / EUIPO）与汇率、运价指数；行情类按日 / 周更新。政策雷达以官方原文优先：`src/data/policy_sources.py` 接入中国政府网、美国 Federal Register、欧盟委员会 Press Corner / taxation-customs、英国 GOV.UK，仅已验证事件进入决策链，搜索 / 模拟结果作为候选层。用户数据回流机制：在授权与脱敏前提下沉淀订单、履约、退款与回款数据，用于运营诊断与远期信用评分。
2. 演示数据：`src/data/synthetic.py` 生成带趋势、季节性、品类差异的合成数据，保证离线可运行。
3. 清洗：`src/data/cleaner.py` 统一 Schema、去重、枚举校验、缺失值填充。
4. 存储：清洗结果写入 `data/processed/clean_data.csv` 与 SQLite。

## 3. 特征工程

针对每个品类 / 市场组合按时间构建：

- 目标变量滞后特征（`lag_1/2/4/8`）
- 滚动统计（4/8 周均值）
- 增长率与差分（销量、搜索热度、价格、竞争度）
- 季节性特征（月份、周数正余弦编码）
- 规划加入外部事件特征：关税政策生效日期、汇率跳变、Prime Day / 黑五等

## 4. 预测模型

### Prophet 基线

- 多源外生回归变量（搜索热度、价格、竞争、评论增长、出口额、榜单排名）+ 周 / 年季节性
- 对目标做对数变换后再拟合，避免负销量预测，提升小样本稳定性
- 输出未来 90 天日粒度预测与 80% 置信区间

### LightGBM 进阶

- 基于多源特征（20 个特征列）的梯度提升回归
- 按时间切分训练 / 测试，评估 MAPE 与 MAE
- 未来预测采用滚动递归：预测一期后更新滞后特征继续预测
- 置信区间由训练残差标准差估计

## 5. 推荐引擎与冲突裁决

综合评分 = 0.35 × 预测增长 + 0.30 × 搜索趋势 + 0.25 × 竞争度（反向）+ 0.10 × 评论增长

看板预测图同时展示 Prophet / LightGBM 两条 90 天预测曲线及各自置信区间；推荐增长按每个组合的回测 MAPE 选优，MAPE 更低的模型作为该组合主预测。

冲突裁决规则：

- 每个大脑输出结论时附带置信度（数据完整度 × 模型拟合度）
- 冲突场景按"置信度 × 决策权重"裁决，权重来源为卖家调研的决策因子排序
- 示例："市场热销但供应链断货"时，供应链 / 政策风险权重更高，推荐转向替代品类或调整备货方案
- 推荐理由根据各维度阈值自动生成中文说明，覆盖高增长、搜索升温、蓝海 / 红海、评论活跃、政策预警等场景

## 6. 评估结果（合成演示数据）

| 模型 | MAPE（均值） |
|------|-------------|
| Prophet 基线 | 3.36% |
| LightGBM 进阶 | 2.29% |

> 口径注：本表 MAPE 基于合成快照 + 轻量对照组，外部代表性待真实数据复核。

进阶模型相对基线 MAPE 下降约 54%，满足计划验收标准（相对提升 ≥ 10%）。

## 7. 贸易决策模块（演示版已实现）

### 7.1 关税与政策风险引擎（`src/trade/policy.py`）

- 内置公开政策事件：美国 2025 年取消 800 美元以下 de minimis 免税、欧盟 2026-07-01 低价值包裹增值税；每日联网快照还会合并国外 / 国内 / 全球政策事件
- 每日政策快照由 `src/data/policy_refresh.py` 生成，写入 `output/policy/latest.json` 与 `output/policy/daily/{date}.json`；DuckDuckGo 失败时回退 Bing 中文检索，并抓取中国政府网最新政策列表作为官方来源
- 看板只展示真实政策事件：模拟占位与门户/百科类结果会被过滤，联网失败的历史真实事件会保留在快照中供持续合并
- 国内政策（出口退税、综试区、海关通关、跨境收款、RCEP 等）与全球政策作用于全部目标市场组合，参与 1980 组合重算
- 有明确税率 / 最低关税的事件沿用关税公式；有成本调整比例的事件作用到采购成本；无数值的新闻类事件按影响等级映射为 ±2%/5%/10% 成本冲击（上限 ±25%）并标注启发式估计
- 对品类 / 市场组合测算政策生效后的有效税率、单件关税与到岸成本变化幅度
- 按利润冲击输出低 / 中 / 高风险，并生成应对建议（转正式清关、调价、切换市场、海外仓本地发货等）

### 7.2 财务贸易成本模型（`src/trade/cost.py`）

- 覆盖采购、关税、汇率、支付通道（PayPal / PingPong / 连连）、认证合规与物流三方案
- 输出单件到岸成本、利润率与汇率敏感性区间（人民币升值 / 贬值 5%）
- 小包直邮 / 海运整柜 / 海外仓本地发货三方案对比

### 7.3 合规与市场准入评估（`src/trade/compliance.py`）

- 按目标市场输出 IOSS / VAT、CE / FCC / FDA / RoHS / CPSC / GPSR 等清单
- 汇总认证成本、周期并输出市场准入可行性评分

### 7.4 知识产权风险筛查（`src/trade/ip.py`）

- 内置演示用商标 / 专利 / 外观设计库，按品类 × 市场输出低 / 中 / 高风险
- 支持候选品名称匹配，未填写时按品类默认基线筛查
- 真实场景可替换为 USPTO / EUIPO 官方公开数据接口

### 7.5 物流运价与时效预测（`src/trade/logistics.py`）

- 内置 SCFI 风格演示运价序列，按美国 / 欧洲 / 东南亚航线预测未来 4 周指数
- 输出运价涨幅、预测单件物流成本、交付时效与拥堵 / 风险等级
- 真实场景可替换为 SCFI / 船司运价接口

### 7.6 多语言舆情与本地化（`src/trade/sentiment.py`）

- 内置英 / 西 / 德 / 日 / 葡情感词库与演示评论，按市场输出多语种情绪分
- 输出评论总数、正 / 负 / 中性占比、趋势与本地化建议
- 真实场景可替换为评论抓取与多语种情感模型

### 7.7 绿色贸易与 CBAM 前瞻（`src/trade/green.py`）

- 按市场 / 品类输出欧盟 CBAM 暴露度、预估碳成本与政策趋势
- 输出低 / 中 / 高风险与碳数据收集、碳成本预留等建议
- 真实场景可替换为 CBAM 申报数据与碳排因子库

### 7.8 数据信用与供应链金融（`src/trade/credit.py`）

- 将政策风险、物流风险、利润空间与经营数据覆盖度映射为可解释的融资就绪评分
- 输出订单稳定性、履约率、退款率、政策风险评分与建议融资档位（供应链金融 / 信用贷 / 小额试单 / 暂不建议）
- 真实场景可替换为授权订单、履约、回款与税务数据，并对接金融机构授信接口

### 7.9 多脑冲突裁决（`src/trade/conflict.py`）

- 将市场增长、舆情、政策、物流、财务利润、市场准入、融资就绪 7 类信号统一到 0-100 分
- 按置信度 × 权重计算裁决后得分，输出冲突等级、风险优先建议与主导信号
- 矛盾案例："市场热销但政策风险高"时，若政策 / 物流信号置信度高，则降低备货规模或调整品类 / 市场

## 10. 真实特征训练口径说明（N1）

主口径为 **132 品类 × 15 市场 = 1980 组合**（周粒度 104 周、共 205,920 行，见 `output/data_status.json` 与 `/api/summary`）。

真实特征增强训练（`scripts/train_real_enhanced.py`）只覆盖**有真实信号**的组合子集（Google Trends / 平台榜单 / UN Comtrade / 爬虫证据等真实源能对齐到 `category × market` 的组合），其余组合走合成特征兜底。因此 `output/data_status.json` 中 `real_training.rows = real_training.combos × 104`，与主口径 1980 不矛盾：

- `rows = real_training.combos × 104 周`；
- `1980 - real_training.combos` 个组合由合成特征补全，参与同一训练/预测/推荐链路；
- 该口径在 `train_real_enhanced.py::_write_status` 的 `caliber_note` 字段同步落盘，便于逐层核对。

## 11. 数据分析与评估

基于 205,920 条周粒度数据（104 周、132 品类 × 15 市场 1980 组合）完成探索性分析：品类 × 市场销量存在明显分层，调味酱料 / 方便速食 / 谷物主食体量领先；搜索热度与销量相关性较强，价格与销量呈弱负相关；销量峰值集中在第 32 周（约 8 月）。

模型评估：LightGBM 进阶 MAPE 2.335%（1980 组合全部有效），最优组合为铁观音 × 东南亚（MAPE 0.744%）；Prophet 基线因本机未安装 cmdstan 无法拟合，MAPE 全为 NaN（口径：合成快照 + 轻量对照组；外部代表性待真实数据复核）。

贸易决策情景：1980 组合中 242 个为高风险，平均毛利率 -8.48%，平均融资就绪评分 77.8，物流三方案中海外仓本地发货平均到岸成本最低。
