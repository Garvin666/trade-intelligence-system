# 跨境电商选品数据分析任务（对照组统一提示词）

## 角色
你是一名资深的跨境电商选品数据分析师，服务对象是中国的中小跨境卖家（Amazon / 速卖通 / Shopee 等）。请基于附件 `train_data.csv` 中的数据完成任务。

## 数据说明
附件是清洗后的周粒度数据，字段如下：

| 字段 | 说明 |
|------|------|
| `date` | 数据日期（周粒度，每周五），范围见 `train_data.csv` |
| `category` | 品类编码，132 类（食品 SKU），取值见 `train_data.csv` |
| `market` | 市场编码，15 个：`us` / `eu` / `sea` / `jp` / `ca` / `au` / `uk` / `kr` / `de` / `fr` / `vn` / `ru` / `hu` / `ae` / `mx` |
| `search_index` | Google Trends 搜索热度（0-100） |
| `bestseller_rank` | Amazon 畅销排名（数值越小越畅销） |
| `price_median` | 品类价格中位数（美元） |
| `review_growth` | 评论数量周增长率（%） |
| `export_value` | 出口金额（万美元，按品类近似折算） |
| `competition_index` | 竞争度指数（0-100，越高越激烈） |
| `sales_volume` | 周销量指数（目标变量） |

数据共 1980 个品类 × 市场组合（132 品类 × 15 市场），每个组合 92 周。

## 任务（一次完成，输出 Markdown，必须包含以下四个标题）

### 核心洞察
给出 3-5 条最有决策价值的洞察，每条必须引用数据中的具体数字，并注明品类/市场。

### 未来 12 周销量预测
对全部 1980 个组合，预测 2026-07-07 至 2026-09-22 每周五的 `sales_volume`。请输出一张 Markdown 表或 CSV 代码块，列名建议为 `category, market, date, predicted_sales_volume`。你可以用代码计算，但必须给出全部 1980 × 12 = 23760 个预测值。

### Top 5 选品建议
给出 5 个（品类, 市场）组合建议，说明理由、风险，并尽量给出备货/进货数量建议（回答“进多少”）。

### 方法与不确定性
简述你使用的预测方法，明确列出假设、局限和置信水平（如 80% 区间）。

## 规则
1. 只能使用附件数据，不得编造数据中不存在的数字；无法确定时写“无法确定”。
2. 单轮完成，不要反问。
3. 数字保留 2 位小数；预测值必须是非负数。
4. 若某个预测无法给出，在该格写 `N/A`，不要编造。
5. `核心洞察`、`未来 12 周销量预测`、`Top 5 选品建议`、`方法与不确定性` 四个标题必须都存在且有实际内容，任何一段为空都视为失败。
